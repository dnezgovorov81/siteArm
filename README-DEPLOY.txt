СТРОЙ МАСТЕР ДОМОФОН — АРМЕНИЯ
Русская версия сайта для согласования.

Публикация через GitHub Pages:
1. Распакуйте ZIP.
2. Загрузите содержимое архива в корень репозитория. В корне должны находиться index.html, styles-v5.css и папка assets. Загружать сам ZIP не нужно.
3. В Settings → Pages выберите Deploy from a branch, затем main и /(root), нажмите Save.
4. Ссылка на сайт появится в разделе Pages после публикации.

Файл .nojekyll оставьте в корне, если он отображается в файловом менеджере.
Все картинки и стили находятся в архиве. Сайт не требует сборки или установки зависимостей.
При обновлении сохраняйте имена и расположение файлов.

Мобильная верстка:
— viewport: width=device-width, initial-scale=1;
— адаптивная ширина страницы до 430 px;
— основной текст и кнопки навигации 18 px;
— сетка навигации 2×2, D-KEYS без разрыва;
— дополнительные стили для экранов шириной до 360 px.

ПРОВЕРКА МОБИЛЬНОЙ ВЕРСТКИ
Проверено в браузере при ширине 320, 390 и 430 px.
Горизонтальной прокрутки и переполнения текста нет.
Все 11 изображений страницы загрузились.
D-KEYS не разрывается по строкам. Основной размер текста — 18 px.
