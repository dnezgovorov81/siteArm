СТРОЙ МАСТЕР ДОМОФОН — АРМЕНИЯ
Русская версия сайта для согласования.

Публикация через GitHub Pages:
1. Распакуйте ZIP.
2. Загрузите содержимое архива в корень репозитория: index.html, styles-v13.css и папку assets. Загружать сам ZIP не нужно.
3. В Settings → Pages выберите Deploy from a branch, затем main и /(root), нажмите Save.
4. Ссылка появится в разделе Pages после публикации.

Файл .nojekyll оставьте в корне. Все картинки и стили находятся в архиве. Сборка и установка зависимостей не нужны.
При обновлении сохраняйте имена и расположение файлов.

Мобильная верстка: viewport=device-width, основной текст 18 px, навигация 2×2, D-KEYS без разрыва.
